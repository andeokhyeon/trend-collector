# GitHub Actions로 자동 실행하기

PC를 켜두지 않아도 서버가 알아서 수집합니다.

---

## 1. 파일 올리기

`.github/workflows/` 폴더의 두 파일을 저장소에 올립니다.

```
git add .
git commit -m "add github actions"
git push
```

> `.github` 폴더는 점으로 시작해서 탐색기에서 안 보일 수 있습니다.
> **보기 → 숨긴 항목**을 켜주세요.

---

## 2. 키 등록하기 (제일 중요)

`.env` 파일은 GitHub에 안 올라가므로, 서버가 쓸 키를 따로 넣어줘야 합니다.

**저장소 → Settings → 왼쪽 Secrets and variables → Actions
→ New repository secret**

아래 9개를 하나씩 등록합니다. 이름은 **정확히** 아래와 같아야 합니다.

| Name | Secret (값) |
|---|---|
| `NAVER_API_KEY` | .env의 같은 항목 값 |
| `NAVER_SECRET_KEY` | 〃 |
| `NAVER_CUSTOMER_ID` | 〃 |
| `SUPABASE_URL` | 〃 |
| `SUPABASE_KEY` | 〃 |
| `NAVER_HUB_CLIENT_ID` | 〃 |
| `NAVER_HUB_CLIENT_SECRET` | 〃 |
| `TOUR_API_SERVICE_KEY` | 〃 |
| `ANTHROPIC_API_KEY` | 〃 |

> 값에 **따옴표를 붙이지 마세요.** `.env`에서 `=` 뒤의 내용만 그대로 복사합니다.

---

## 3. 잘 되는지 확인

**저장소 → Actions 탭 → 왼쪽 "수집기" → Run workflow**

수동으로 한 번 돌려봅니다. 초록색 체크가 뜨면 성공이고,
로그를 열면 평소 검은 창에서 보던 내용이 그대로 나옵니다.

빨간색이면 로그에서 어느 줄이 실패했는지 볼 수 있습니다.

---

## 실행 주기

| 작업 | 주기 | 한국 시간 |
|---|---|---|
| 수집기 | 2시간마다 | 00:17, 02:17, 04:17 ... |
| 키워드 미리쌓기 | 하루 1번 | 새벽 03:23 |

**주기를 바꾸려면** `.github/workflows/collector.yml`의 `cron` 줄을 고칩니다.

```yaml
- cron: '17 */2 * * *'    # 2시간마다
- cron: '17 * * * *'      # 매시간
- cron: '17 */4 * * *'    # 4시간마다
```

시간은 **UTC 기준**입니다. 한국 시간 = UTC + 9시간.

---

## 알아두실 점

**비공개 저장소는 월 2,000분까지 무료입니다.**
수집기 1회가 약 3분이면 2시간마다가 안전합니다(월 약 1,080분).
매시간으로 늘리면 월 2,160분이라 한도를 넘습니다.

**공개 저장소는 무제한입니다.** 매시간으로 돌려도 됩니다.

**공개 저장소는 60일간 커밋이 없으면 스케줄이 자동으로 꺼집니다.**
가끔 커밋하거나, Actions 탭에서 다시 켜주세요.

**정각은 요청이 몰려 지연됩니다.** 그래서 17분, 23분처럼 비켜서 잡았습니다.
몇 분 늦게 도는 건 정상입니다.

**`2_대시보드_실행.bat`** — 대시보드를 볼 때만 쓰면 됩니다.

**`3_데이터_수집.bat`, `7_키워드_미리쌓기.bat`** — 서버가 알아서 도니
급할 때만 쓰시면 됩니다. Windows 작업 스케줄러도 이제 필요 없습니다.
